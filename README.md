# 1007 page — 주간회의 공동 작성

6명이 웹 화면에 바로 작성하면 항목별로 취합되고, 누구나 원본 양식의 한글(HWPX) 파일을 다운로드합니다.

## 배포 구조

GitHub Pages는 `index.html`을 제공합니다. 페이지 안의 iframe은 기존 주간회의 앱을 표시합니다.
공동 저장, 3초 주기 갱신, 주차 이동, 한글 파일 생성은 기존 앱이 처리합니다.
기존 앱과 저장소가 계속 운영되어야 하며, 독립된 GitHub 서버로 데이터를 이전하는 방식은 아닙니다.
표시 또는 다운로드가 브라우저에서 제한되면 **새 창으로 열기**를 사용하세요.

- 기존 앱: https://weekly-hwpx-261007.edu9601521.chatgpt.site/
- 공개 저장소 예정 이름: `1007-page`
- GitHub Pages: 저장소 Settings → Pages → Deploy from a branch → `main` / `/ (root)`

## 사용

1. 이름을 선택하고 공지사항·전주·금주·차주·대외활동을 작성합니다.
2. 입력 내용이 자동으로 저장되어 공동 취합 화면에 반영됩니다.
3. 한글 다운로드를 누르면 작성자 이름이 포함된 취합 파일을 받습니다.
4. 매주 월요일 한국 시간 기준으로 금주 → 전주, 차주 → 금주로 이동합니다.

별도 로그인은 없으며, 주소를 아는 사람이 공동 자료를 읽고 수정할 수 있습니다.
